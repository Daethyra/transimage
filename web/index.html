Help & tips — video → GIF

Choosing FPS

15 fps is a good default. Going above 24 rarely looks smoother and makes the file noticeably larger.

Colors

256 is the maximum GIF supports. Dropping to 128 or 64 is the single biggest way to shrink the file size, at the cost of some color banding.

Dither

Smooths gradients but increases file size. Turn it off for flat-color sources like screen recordings, memes, or 2D animation.

Trim first, then resize

Trim with the scrub bar and the Start/End buttons before exporting. Cropping or shortening the clip is always cheaper than lowering quality.

File size tips, in order of impact

  • Trim the clip with Start/End.
  • Lower Max width to 320–480 px.
  • Reduce Colors to 128.
  • Disable Dither.
  • Lower FPS to 10.

Help & tips — image conversion

Which format should I pick?

  • PNG — lossless, keeps transparency. Best for screenshots, logos, graphics.
  • JPEG — smallest for photos, no transparency. Quality 90–95 looks identical to the source.
  • WebP — usually the smallest file with good quality, and it keeps transparency.
  • BMP — uncompressed, large, and rarely what you want. Included for completeness.

Quality slider

Only affects JPEG and WebP. 92 is a good balance. Below 80 the artifacts become visible; above 95 the file grows without a noticeable quality gain.

Transparency

Converting a transparent PNG to JPEG flattens it onto a white background, because JPEG has no alpha channel. If you need transparency preserved, pick PNG or WebP.
